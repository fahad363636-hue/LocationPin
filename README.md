# 📍 LocationPin

**LocationPin** is a modern map-based location utility designed for Rootless jailbreaks.

Developed by **Mohamedjj**.

## ✨ Features

- 🗺️ Interactive map interface
- 📍 Drop a pin to select a location
- 🔎 Location search
- ⭐ Save favorite locations
- 📱 Designed for Rootless jailbreaks
- 🌙 Light & Dark Mode
- 🌐 Clean and simple interface

## 📱 Compatibility

- Rootless jailbreak
- iOS 15 – 18
- arm64 / arm64e
